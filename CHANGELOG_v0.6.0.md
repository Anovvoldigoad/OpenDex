# v0.6.0

- Removed DroidUP APK dependency completely.
- Removed native/OEM freeform windowing dependency.
- Added custom desktop shell.
- Added one trusted virtual display per app window.
- Added TextureView-backed app rendering.
- Added custom title bar and desktop move/resize/maximize/minimize/close controls.
- Added taskbar and app drawer.
- Added per-display direct touch/key injection through Shizuku.
- Desktop now naturally follows the phone's actual landscape viewport rather than using a fixed
  16:9 virtual desktop resolution.
